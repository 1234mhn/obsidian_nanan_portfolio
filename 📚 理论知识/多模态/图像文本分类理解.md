# 🖼️ 图像-文本分类理解（用户原稿 + 楠楠整理）

> 本卡片规则：**用户先给理解，楠楠负责整理/修正/补全后存档**（2026.8.1 订立）

---

## 第一部分 · 用户的理解（2026.8.1 原稿）

### 为什么要把图像和文本放在一起

想象你在网上看到一张图片，旁边配了一段说明文字。
- 只看图片：可能模糊，不确定在说什么
- 只看文字：可能太抽象，不够直观
- 图片 + 文字一起看：理解更准确、更全面

这就是图像-文本（多模态）分类的核心思想：让模型同时"看"图又"读"文，综合判断属于哪个类别。

### 整体流程（三步走）

```
输入
├── 图像 ──→ [图像编码器] ──→ 图像特征向量
└── 文本 ──→ [文本编码器] ──→ 文本特征向量
        ↓
   [特征融合模块]
        ↓
   [分类器] ──→ 类别标签
```

**第一步：分别提取特征**
- 图像编码器：常用 CNN（ResNet、EfficientNet）或 ViT，把一张图变成一个数字向量 [0.3, 0.7, 0.1, ...]，代表形状、颜色、纹理
- 文本编码器：常用 BERT、RoBERTa、CLIP 文本编码器，把文字变成向量，代表语义

**第二步：特征融合**（最核心）
| 融合方式 | 做法 | 特点 |
|:----|:----|:----|
| 早期融合 | 直接把两个向量拼接 | 简单快速，但没有交互 |
| 晚期融合 | 两路分别预测，再投票合并 | 灵活，但缺跨模态信息 |
| 交叉注意力融合 | 图文互相"关注"对方 | 效果最好，但计算量大 |

交叉注意力例子：文字提到"红色跑车"→模型重点看图片红色区域和车轮廓；图片有猫→模型重点关注文字里动物描述。

**第三步：分类**
融合后的特征送进分类器（几层全连接层），输出每个类别概率，取最高。

### 典型代表模型
CLIP（OpenAI）、ViLBERT、ALBEF、BLIP / BLIP-2

### 关键挑战
1. 模态对齐：图特征和文特征是"两种语言"，要映射到同一空间才能比较
2. 数据不平衡：图文配对数据标注成本高
3. 噪声问题：网上抓的图文对，文字和图片往往不完全对应

### 一句话总结
> 图像-文本分类 = 用两个编码器分别读懂图和文 → 通过融合让两者"互相参考" → 最终做出更准确的类别判断。

## 第二部分 · 楠楠的整理与修正（2026.8.1）

### ✅ 理解到位的地方（80%）
- 图文结合动机、双编码器提特征、模态对齐/不平衡/噪声三大挑战、交叉注意力思想 —— 全部正确

### ❌ 关键修正（20%，但很关键）

**CLIP 不属于上面描述的"融合→分类器"路线，它属于"对比派"。**

```
用户原稿流程（融合派，适用于 ViLBERT/ALBEF/BLIP）：
  图像编码 → 文本编码 → 特征融合 → 分类器 → 类别

CLIP 实际流程（对比派）：
  图像编码 → 图片向量 ─┐
                       ├→ 相似度 → 谁近谁是哪类
  文本编码 → 文字向量 ─┘
  没有融合模块，没有分类器
```

### 🧭 两大流派（给导师讲的必备视角）

| 流派 | 做法 | 特点 | 代表 |
|:----|:----|:----|:----|
| 融合派 | 图文特征先融合（拼接/交叉注意力），再进分类器 | 效果好，但要训练 | ViLBERT、ALBEF、BLIP |
| 对比派 | 图文映射到同一空间，直接算相似度 | 零样本、免训练，但没有交互 | CLIP |

**一句话区分**：融合派让图文"商量"后判断；对比派让图文"站好位置"量距离。

### 💡 对项目的意义
- 脑部CT-CLIP项目走**对比派**，零样本正好解决医学标注稀缺、冷启动快
- 下一步 few-shot 微调 = 往融合派效果靠拢，是研究切入点

### 📝 修正后的完整理解（可直接用于讲项目）
> 我做的是脑部CT图文分类，走对比学习派（CLIP）：两个编码器把图文映射到同一空间，相似度定类别，零样本无需标注。我了解融合派（ViLBERT/BLIP）的路线，选择对比派是因为医学标注稀缺；下一步用 few-shot 微调补上效果优势。
