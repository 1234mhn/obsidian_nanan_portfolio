# 📉 PCA（主成分分析）

## 一句话

> **把高维数据压缩到低维，同时尽量保留原始信息。** 本质就是降维。

## 算法四步

| 步骤 | 做什么 | 为什么 |
|:----|:------|:------|
| ① 数据中心化 | 每个特征减去它的均值 | 让数据以零为中心，**不然结果会偏移，数学上就不正确** |
| ② 算协方差矩阵 | 看各个特征之间的相关性 | 找特征之间的关系——相关性强说明信息有冗余 |
| ③ 算特征值/特征向量 | 找出"数据最分散的方向" | 特征值越大 → 这个方向保留的信息越多 |
| ④ 选前K个投影 | 取最大的K个特征向量，把数据投影过去 | K个方向就保留了大部分信息 |

## 核心概念

| 概念 | 说明 |
|:----|:------|
| **主成分** | 数据方差最大的方向，第一个主成分最重要 |
| **协方差** | =0不相关 → 方向是坐标轴；>0正相关 → 方向在两者之间；<0负相关 |
| **解释方差比** | 每个主成分保留了多少原始信息 |
| **n_components** | 降到几维？选2（画图）或保留95%方差 |

## 什么时候用？

| 场景 | 为什么用PCA |
|:----|:-----------|
| 数据有100个特征，画不了图 | PCA降到2维 → 直接画散点图看分布 |
| 特征太多，模型跑太慢 | PCA压缩到20维 → 快10倍 |
| 医学影像特征高维（像素级） | PCA提取最重要的模式 |

## 关键：特征相关性决定了主成分方向

> 协方差体现了特征之间的相关性：
> - 花瓣长和花瓣宽高度相关 → PCA合并成一个"花瓣大小"的方向
> - 这一方向就解释了**92.5%** 的信息
>
> **PCA本质上就是：把相关性高的特征合并成一个新特征，丢掉冗余信息。**

## 代码

```python
from sklearn.decomposition import PCA
pca = PCA(n_components=2)     # 降到2维
X_reduced = pca.fit_transform(X)
```
