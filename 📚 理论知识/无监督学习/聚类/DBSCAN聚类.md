# 🎯 DBSCAN（基于密度的聚类）

## 一句话

> **把"离得近的一串"归成一堆，离群点自动不要。**

## 和 K-Means 的区别

| | K-Means | DBSCAN |
|:--|:-------|:-------|
| 能分什么形状 | 只能分**圆形**的堆 | **任意形状**（月亮、环形都行） |
| 需要指定K吗？ | 是（必须说分几堆） | **不用**，自动识别 |
| 离群点处理 | 硬塞进某堆 | **自动标为离群点** |
| 结果稳定性 | 不同起点可能不同 | 稳定 ✅ |

## 两个参数

| 参数 | 意思 | 调参方向 |
|:----|:----|:--------|
| **eps** | 邻居半径 | 小了→分太细；大了→全归一堆 |
| **min_samples** | 最少几个邻居才算核心 | 小了→容易成一堆；大了→容易成离群点 |

## 三种点

```
● 核心点 — 半径eps内有≥min_samples个邻居
○ 边界点 — 在核心点附近，但自己邻居不够
✕ 离群点 — 谁也挨不着
```

## 代码

```python
from sklearn.cluster import DBSCAN
model = DBSCAN(eps=0.3, min_samples=5)
model.fit(X)
labels = model.labels_      # -1 = 离群点
```

## 什么时候用

| 场景 | 选 |
|:----|:---|
| 数据是圆形的一堆堆 | K-Means（更快） |
| 数据形状奇怪（月亮、环形） | DBSCAN ✅ |
| 数据里有明显的离群点 | DBSCAN ✅（自动标出来） |
