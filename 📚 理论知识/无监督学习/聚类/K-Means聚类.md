# 🎯 K-Means 聚类

## 一句话

> **自动把数据分成K堆，每堆离自己的中心最近。**

## 算法流程（4步循环）

```
① 随机选K个点作为"中心"
② 算每个点到各个中心的距离 → 离谁近就归谁
③ 重新算每一堆的中心（取平均）
④ 重复②③，直到中心不再变化
```

## 代码（就三行）

```python
from sklearn.cluster import KMeans
model = KMeans(n_clusters=3)
model.fit(X)
labels = model.labels_
```

## 唯二要你决定的参数

### ① K 值 — 分几堆？

**肘部法则**：跑K=1,2,3,4... 看误差下降速度，拐点就是最佳K

```
K=1 → 误差很大
K=2 → 小了
K=3 → 更小了
K=4 → 没怎么变  ← 这就是肘部！
```

### ② 随机初始化（n_init）

不同起点可能得出不同结果。设 `n_init=10` 跑10次取最好的。

## K-Means 的坑

### ① 只能分"圆形"的堆

```
✅ 能分的               ❌ 不能分的
  ● ● ●                ☽ ☽ ☽
  ● ● ●     → 可以     ☾ ☾ ☾    → 分不开
  ● ● ●                ☽ ☽ ☽
```

月亮形状、环形数据 → K-Means 废了，得用 **DBSCAN**

### ② 对特征尺度敏感

身高170cm + 体重65kg → 距离计算时身高主导。需要**归一化**。

### ③ 不同起点不同结果

K-Means 不一定收敛到全局最优，多跑几次取最好的。

## 监督 vs 无监督

| | 监督学习 | 无监督学习（K-Means） |
|:--|:-------|:-------------------|
| 标签 | ✅ 有正确答案 | ❌ 没标签，自己发现规律 |
| 目标 | 学习从X到y的映射 | 发现数据的内在结构 |
| 评价 | 准确率 | 没有绝对标准（有轮廓系数） |
