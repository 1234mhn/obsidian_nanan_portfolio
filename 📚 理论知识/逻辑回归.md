# 📊 逻辑回归（Logistic Regression）

> **名字带"回归"，本质是分类。身体是回归的（算连续值），灵魂是分类的（按概率归类）。**

## 核心三步

| 步骤 | 说明 |
|:----|:------|
| ① 算连续值 | 和线性回归一样，算 z = wx + b（可以是任何数） |
| ② Sigmoid函数 | 把z压缩到0~1之间：p = 1 / (1 + e⁻ᶻ) |
| ③ 阈值判断 | 设定阈值（通常0.5），≥为A类，<为B类 |

## Sigmoid 函数

```
z很小（负很大）→ p ≈ 0     → 大概率负类
z = 0          → p = 0.5   → 临界点（决策边界）
z很大（正很大）→ p ≈ 1     → 大概率正类
```

## 昨天（2026.7.29）的实战

### 场景：学习时长 → 是否通过考试

**学到的参数：**
```
权重 w = 2.1061  （每多学1小时，对"通过"的推力）
偏置 b = -6.3075
模型公式：z = 2.1061 × 时长 + (-6.3075)
```

**决策边界：**
```
p = 0.5 时，z = 0
0 = 2.1061 × 时长 - 6.3075
→ 时长 ≈ 2.99 小时
→ 学不到3小时大概率挂，超过3小时大概率过
```

### 两种预测方式

| 方式 | 方法 | 输出 |
|:----|:----|:-----|
| 硬预测 | `predict()` | 直接出 0 或 1 |
| 软预测 | `predict_proba()` | 输出概率 [p(挂), p(过)] |

### 评估指标

**准确率 + 混淆矩阵：**
```
            预测挂   预测过
真实挂       [TN]    [FP]
真实过       [FN]    [TP]
```

## 阈值与代价（2026.7.30 深化讨论）

### 默认阈值为什么是0.5？

> 因为0~1正中间，两种错误代价一样时各占一半。适用于猫狗识别、及格/不及格（代价相当）的场景。

### 代价不对称时怎么调阈值？

**场景：癌症筛查**
| 真实 | 预测健康 | 预测癌症 |
|:----|:--------|:--------|
| 健康 ✅ | TN（没事） | FP（虚惊一场） |
| 癌症 ❌ | ‍ **FN（漏诊！）** | TP（救了命） |

漏掉一个癌症 = 人命关天。所以：
- 阈值**调低**（如0.3）→ 宁可误判健康人为癌症，也不漏真癌症

**场景：垃圾邮件过滤**
误删一封重要邮件代价更大 → 阈值**调高**（如0.8）

### 与假设检验的关联

用户自述联想到假设检验，方向完全正确：

| 假设检验 | 逻辑回归对应 |
|:--------|:-----------|
| 第一类错误 α（弃真） | 把健康人判为癌症 → FP |
| 第二类错误 β（取假） | 把癌症判为健康 → FN |
| 调α↓则β↑ | 调阈值 → 两种错误率此消彼长 |

> 工程上通过 **ROC 曲线 + Youden Index** 找阈值平衡点，让总代价最小。

### 测试集100%≠完美

> 只能说明在这个数据里正确率100%，换数据未必。关键看泛化能力。
> 可能的原因：①数据太简单（如鸢尾花数据集）②模型过拟合了此数据
