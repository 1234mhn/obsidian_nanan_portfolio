# 📊 逻辑回归（Logistic Regression）

> **名字带"回归"，本质是分类。身体是回归的（算连续值），灵魂是分类的（按概率归类）。**

## 核心三步

| 步骤 | 说明 |
|:----|:------|
| ① 算连续值 | 和线性回归一样，算 z = wx + b（可以是任何数） |
| ② Sigmoid函数 | 把z压缩到0~1之间：p = 1 / (1 + e⁻ᶻ) |
| ③ 阈值判断 | 设定阈值（通常0.5），≥为A类，<为B类 |

## Sigmoid 函数

```
z很小（负很大）→ p ≈ 0     → 大概率负类
z = 0          → p = 0.5   → 临界点（决策边界）
z很大（正很大）→ p ≈ 1     → 大概率正类
```

## 昨天（2026.7.29）的实战

### 场景：学习时长 → 是否通过考试

**学到的参数：**
```
权重 w = 2.1061  （每多学1小时，对"通过"的推力）
偏置 b = -6.3075
模型公式：z = 2.1061 × 时长 + (-6.3075)
```

**决策边界：**
```
p = 0.5 时，z = 0
0 = 2.1061 × 时长 - 6.3075
→ 时长 ≈ 2.99 小时
→ 学不到3小时大概率挂，超过3小时大概率过
```

### 两种预测方式

| 方式 | 方法 | 输出 |
|:----|:----|:-----|
| 硬预测 | `predict()` | 直接出 0 或 1 |
| 软预测 | `predict_proba()` | 输出概率 [p(挂), p(过)] |

### 评估指标

**准确率 + 混淆矩阵：**
```
            预测挂   预测过
真实挂       [TN]    [FP]
真实过       [FN]    [TP]
```
