# 🎯 SVM（支持向量机）

## 一句话

> **找一个"分界线"，把不同类别的数据尽可能宽地分开。**

## 核心思想

想象桌上有两堆豆子（红豆和绿豆）。SVM 就是在中间画一条线，而且**不是随便画**——它要画一条让两边豆子离这条线**越远越好**的线。

```
  红豆区              绿豆区
    ● ●                ○ ○
  ● ● ●   ← 间隔 →     ○ ○ ○
    ● ●   ← 最大 →     ○ ○
       ↑ 支持向量 ↑       ↑ 支持向量
```

**支持向量** = 离分界线最近的那些点，它们"撑"着这条分界线的位置。

## 核技巧（SVM的精髓）

> **低维空间分不开 → 升到高维 → 分开 → 投影回低维**

### 灵魂三问

| 问题 | 答案 |
|:----|:-----|
| 为什么分不开？ | 数据在低维空间可能是交错、环状、非线性的 |
| 怎么升维？ | 用核函数（Kernel Function）自动映射到高维 |
| 能不手动算高维吗？ | 可以！核技巧直接在低维算高维的点积结果 |

### 常见核函数

| 核函数 | 说明 | 适用场景 |
|:------|:-----|:---------|
| 线性核 | 不需要升维，线性可分时用 | 文本分类、高维稀疏数据 |
| RBF核（高斯核） | 最常用，适合大多数情况 ✅ | 非线性数据、中小数据集 |
| 多项式核 | 升到多项式空间 | 图像分类（不如图像专用模型） |

## 关键参数

```python
from sklearn.svm import SVC

model = SVC(
    C=1.0,          # 正则化强度（越大越严格划分，越小允许容错）
    kernel='rbf',   # 核函数（'linear', 'poly', 'rbf', 'sigmoid'）
    gamma='scale',  # RBF核的宽度（越大决策边界越曲折）
)
```

| 参数 | 值小 | 值大 |
|:----|:----|:-----|
| C | 允许更多错分 → 欠拟合 | 严格分类 → 过拟合 |
| gamma（RBF） | 决策边界平滑 | 决策边界曲折 |

## 优缺点

| 优点 | 缺点 |
|:----|:-----|
| 高维数据表现好 | 大数据集训练慢（O(n²~n³)） |
| 核技巧能处理非线性 | 参数调优难（C + kernel + gamma组合多） |
| 理论完美（全局最优解） | 不直接输出概率（需额外设置） |

## 与逻辑回归的区别（2026.7.30 讨论）

| | 逻辑回归 | SVM |
|:--|:-------|:----|
| 目标 | 找到分界线就行 | 找到**最宽马路**的分界线 |
| 关注点 | 所有数据点 | **只看边界附近的点（支持向量）** |
| 输出 | 概率 | 类别和距离 |

> **用户自述理解：** SVM就是两个类之间找到中间地带最大的带宽、离两侧分类最远的距离。只需要看离带宽最近的那些点就可以了。

### 核技巧的魔力

> 低维分不开 → 升到高维 → 切开 → 投影回来。
> **而且不用手动算高维坐标**，核函数直接在低维算出高维的结果。

|:-------|:-----|
| 标签转换 | y = 0/1 → y = -1/+1（SVM要求） |
