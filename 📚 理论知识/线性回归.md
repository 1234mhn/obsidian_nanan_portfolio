# 📈 线性回归（Linear Regression）

## 一句话

> **在多个特征上做线性拟合，找一条线/一个平面，让所有数据点到它的距离最小。**

## 本质

| 维度 | 说明 |
|:----|:------|
| 输入 | 特征（一个或多个） |
| 输出 | 连续数值 |
| 公式 | y = wx + b（一元） / y = w₁x₁ + w₂x₂ + ... + b（多元） |
| 目标 | 最小化预测值与真实值的差距（MSE） |

## 分类 vs 回归

| | 回归 | 分类 |
|:--|:----|:-----|
| 输出 | 连续数值 | 离散类别标签 |
| 本质 | 预测"多少" | 判断"是哪一类" |
| 例子 | 预测播放量、房价、温度 | 是不是垃圾邮件、好评/差评 |
| 类比 | 这菜多少钱？ | 这是川菜还是粤菜？ |

## 实操场景（韩语自媒体）

- **线性回归**：根据点赞数、评论数、发布时间 → 预测下条视频播放量
- **逻辑回归**：根据同样因素 → 判断能否破万（能/不能）

## 关键概念

| 概念 | 说明 |
|:----|:------|
| 一元线性回归 | y = wx + b，只有一个特征 |
| 多元线性回归 | y = w₁x₁ + w₂x₂ + ... + b，多个特征 |
| 最小二乘法 | 最小化残差平方和来求w和b |
| R²（决定系数） | 模型拟合的好坏，1=完美，0=没用 |
| 过拟合 | 学得太多，把噪音也学了 |
| 欠拟合 | 学得不够，没抓住规律 |

## 80/20 定位

线性回归属于**快速过**的算法。理解它的思想（拟合一条线）就够了，比它"升级版"的正则化回归（Ridge/Lasso）更有用。
