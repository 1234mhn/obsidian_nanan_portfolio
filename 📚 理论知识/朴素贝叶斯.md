# 🎲 朴素贝叶斯（Naive Bayes）

## 一句话

> **基于概率做判断：看到某些特征 → 算出属于各个类别的概率 → 选概率最大的。**

## 核心公式（贝叶斯定理）

```
P(类别|特征) = P(特征|类别) × P(类别) / P(特征)

后验概率   = 似然    × 先验概率 / 证据
```

### 直观理解

> 你在街上看到一个人穿白大褂戴口罩 → 更可能是医生而不是厨师

- **先验概率**：街上原本有多少比例是医生（P(医生)）
- **似然**：医生穿白大褂的概率有多大（P(白大褂|医生)）
- **证据**：街上穿白大褂的总人数（P(白大褂)）
- **后验概率**：看到穿白大褂的人，他是医生的概率（P(医生|白大褂)）

## "朴素"在哪？

> **假设所有特征相互独立。** 比如判断垃圾邮件时，假设"含'免费'"和"含'点击'"这两个特征互不影响。

现实中这个假设几乎不成立，但——**实际效果出奇地好！**

## 三种朴素贝叶斯

| 变种 | 适用场景 | 特征类型 |
|:----|:---------|:--------|
| 高斯朴素贝叶斯（GaussianNB） | 连续数值 | 身高、温度、价格 |
| 多项式朴素贝叶斯（MultinomialNB） | 计数/词频 | 文本分类、词袋模型 |
| 伯努利朴素贝叶斯（BernoulliNB） | 二值特征 | 是否出现、0/1 |

## 典型应用：文本分类

```
"恭喜你，免费领取iPhone！" → 垃圾邮件 ✅
"明天下午3点开会，请准时参加" → 正常邮件 ✅
```

朴素贝叶斯在**文本分类**中是经典算法，简单、快、效果好。

## 优缺点

| 优点 | 缺点 |
|:----|:-----|
| 训练极快（一次扫描计算概率） | 特征独立性假设太强 |
| 小数据上表现好 | 如果遇到训练集没见过的特征 → 概率为0（可用拉普拉斯平滑解决） |
| 数据少也能出结果 | 对特征之间的关联完全不敏感 |

## 80/20 定位

属于**快速过**的算法。理解三大概率（先验、似然、后验）和"朴素假设"就够了。在文本分类/垃圾邮件过滤中仍然很强。
