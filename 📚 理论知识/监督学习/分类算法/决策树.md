# 🌳 决策树（Decision Tree）

## 一句话

> **像玩"20个问题"一样，一层层问下去，每次把数据分成两拨，直到分出结果。**

## 核心思想

决策树=一堆if-else组合。根节点到叶子节点是一条"判断路径"。

```
天气 = 晴？
├── 是 → 湿度 > 70%？
│       ├── 是 → 不出门
│       └── 否 → 出门
└── 否 → 下雨？
        ├── 是 → 不出门
        └── 否 → 出门
```

## 关键概念

| 概念 | 说明 |
|:----|:------|
| 根节点 | 最顶层的第一次分裂 |
| 内部节点 | 中间的分裂点 |
| 叶子节点 | 最终的分类结果 |
| 分裂 | 根据某个特征把数据分成两组 |
| 树深度 | 从根到叶的最长路径 |

## 分裂标准

| 标准 | 说明 | 用在哪 |
|:----|:----|:------|
| 信息增益（ID3） | 分裂后"不纯度"下降得越多越好 | C4.5 / ID3 |
| 基尼系数（CART） | 分裂后混乱程度越低越好 | CART（sklearn默认） |

**直观理解：**

```
分裂前的数据：    [A,A,A,B,B]  → 混乱度较高
分裂后的两组：
  └─ 第一组：    [A,A,A]      → 纯净！信息增益大
  └─ 第二组：    [B,B]        → 纯净！信息增益大
```

## 最优点

| 优点 | 缺点 |
|:----|:-----|
| 可解释性强（白盒模型） | 容易过拟合（树枝太茂盛） |
| 不需要归一化 | 对微小变化敏感 |
| 能处理非线性关系 | 不稳定（数据稍变，树全变） |

## 80/20 定位

属于**快速过**的算法。核心就两个点：
1. 它怎么分裂的（信息增益/基尼系数）
2. 怎么防止过拟合（剪枝、限制深度）

然后直接上随机森林——单棵决策树的威力有限，但一群树（随机森林）就很猛了。

### 核心参数

```python
from sklearn.tree import DecisionTreeClassifier

model = DecisionTreeClassifier(
    max_depth=3,           # 限制树深度（防过拟合）
    min_samples_split=10,  # 节点分裂最小样本数
    min_samples_leaf=5,    # 叶子节点最小样本数
    criterion='gini'       # 分裂标准（'gini'或'entropy'）
)
```
