# 📊 逻辑回归（Logistic Regression）

> **名字带"回归"，本质是分类。身体是回归的（算连续值），灵魂是分类的（按概率归类）。**

## 核心三步

| 步骤 | 说明 |
|:----|:------|
| ① 算连续值 | 和线性回归一样，算 z = wx + b（可以是任何数） |
| ② Sigmoid函数 | 把z压缩到0~1之间：p = 1 / (1 + e⁻ᶻ) |
| ③ 阈值判断 | 设定阈值（通常0.5），≥为A类，<为B类 |

## Sigmoid 函数

```
z很小（负很大）→ p ≈ 0     → 大概率负类
z = 0          → p = 0.5   → 临界点（决策边界）
z很大（正很大）→ p ≈ 1     → 大概率正类
```

## 昨天（2026.7.29）的实战

### 场景：学习时长 → 是否通过考试

**学到的参数：**
```
权重 w = 2.1061  （每多学1小时，对"通过"的推力）
偏置 b = -6.3075
模型公式：z = 2.1061 × 时长 + (-6.3075)
```

**决策边界：**
```
p = 0.5 时，z = 0
0 = 2.1061 × 时长 - 6.3075
→ 时长 ≈ 2.99 小时
→ 学不到3小时大概率挂，超过3小时大概率过
```

### 两种预测方式

| 方式 | 方法 | 输出 |
|:----|:----|:-----|
| 硬预测 | `predict()` | 直接出 0 或 1 |
| 软预测 | `predict_proba()` | 输出概率 [p(挂), p(过)] |

### 评估指标

**准确率 + 混淆矩阵：**
```
            预测挂   预测过
真实挂       [TN]    [FP]
真实过       [FN]    [TP]
```

## 进阶①：多分类 → Softmax（2026.7.30 攻克）

### 问题
Sigmoid 只能输出一个概率 p（另一类就是 1-p）→ 只能处理二分类。
遇到3类以上（如医学：正常/良性/恶性肿瘤）就不行了。

### 解法：Softmax

> Sigmoid 的升级版，可以输出 **K 个类别的概率**，且所有概率之和 = 1

**公式对比：**

| | Sigmoid（二分类） | Softmax（多分类） |
|:--|:---------------|:----------------|
| 输出 | p ∈ (0,1) | p₁, p₂, ..., pₖ 各 ∈ (0,1) |
| 总和 | p + (1-p) = 1 | p₁ + p₂ + ... + pₖ = 1 |
| 适用 | 二分类 | 多分类 |

**Softmax 公式：**

```
对于第 i 个类别：pᵢ = e^zᵢ / (e^z₁ + e^z₂ + ... + e^zₖ)

每个类别有自己的权重 wᵢ 和偏置 bᵢ
z₁ = w₁·x + b₁  → 类别1的得分
z₂ = w₂·x + b₂  → 类别2的得分
z₃ = w₃·x + b₃  → 类别3的得分
```

**直观理解：** 给每个类别算一个得分 → 用 e^z 放大差异 → 归一化 → 得分最高的就是预测类别。

**Loss 也要换：** 二分类交叉熵 → 多分类交叉熵（Categorical Cross-Entropy）。

### 代码改造思路

在手写版的基础上：
1. `w` 从形状 `(n_features,)` 变成 `(n_features, n_classes)`
2. `sigmoid(z)` 换成 `softmax(z)`
3. `compute_loss()` 换成多分类交叉熵
4. `predict()` 选概率最大的类别

## 进阶②：正则化 L1 / L2（2026.7.30 攻克）

### 要解决的问题

在手写代码里，`w` 可以任意大。w 越大 → 模型越依赖某些特征 → **过拟合**：

```
w = [0.1, 0.2, 100]  ← 第三个特征权重超大
→ 新数据里这个特征稍微变一点，预测结果天翻地覆
→ 过拟合了！
```

### 思路：给 Loss 加惩罚

```
新 Loss = 原 Loss + λ × 惩罚项

λ（lambda）= 你控制的惩罚力度
λ 越大 → w 被压得越小 → 模型越简单
λ 越小 → 几乎不管 → 和原来一样
```

### L1 vs L2 对比

| | L1（Lasso） | L2（Ridge） |
|:--|:----------|:----------|
| 惩罚 | `λ × Σ\|wᵢ\|` | `λ × Σ wᵢ²` |
| 效果 | **让不重要的特征 w 变成 0** | **让所有 w 变小但不归零** |
| 适合 | 特征很多，想做**特征选择** | 特征不多，都想用但别太猛 |
| 直观 | 把不重要的直接砍掉 | 压一压别太出风头 |

### 代码怎么改

在 `train()` 函数里：

```python
def compute_loss_l2(y_hat, y, w, lambda_reg):
    m = len(y)
    base_loss = -1/m * np.sum(y * np.log(y_hat + 1e-9) + (1-y) * np.log(1 - y_hat + 1e-9))
    reg_loss = lambda_reg / (2*m) * np.sum(w**2)  # 👈 加这一项
    return base_loss + reg_loss
```

梯度也要跟着改：

```python
dw = 1/m * np.dot(X.T, (y_hat - y)) + (lambda_reg/m) * w  # 👈 多这一项
```

### 什么时候用哪个

| 场景 | 推荐 |
|:----|:----|
| 特征很多，大部分不重要 | L1（自动特征选择） |
| 特征不多且都有用 | L2 |
| 不确定 | 先用 L2（更稳定） |

## 进阶③：评估指标 — 不止看准确率（2026.7.30 攻克）

### 为什么准确率不够用？

> 100个病人里只有5个真有癌症，模型全都判健康 → 准确率95%
> 但一个癌症都没查出来，等于废物。

### 混淆矩阵复习

```
             预测健康    预测癌症
真实健康       TN          FP
真实癌症       FN          TP
```

### 四个关键指标

| 指标 | 公式 | 回答的问题 |
|:----|:----|:----------|
| **准确率** | (TP+TN) / 总数 | 整体猜对的比例 |
| **精确率** | TP / (TP+FP) | 我判为癌症的，到底多少真是癌症 |
| **召回率** | TP / (TP+FN) | 真癌症里，我查出来了多少 |
| **F1分数** | 2×精×召 / (精+召) | 精确率和召回率的调和平均 |

### 医学场景看哪个

**癌症筛查 → 看重召回率**
> 宁可误诊（FP多），也不能漏掉一个真癌症（FN=0最好）

**确诊复查 → 看重精确率**
> 你说我是癌症？最好别搞错，不然要开刀的

### AUC（ROC曲线下的面积）

> 一句话：**AUC = 模型把正类排在负类前面的能力**

- AUC = 1.0 → 完美分类
- AUC = 0.5 → 纯瞎猜（和抛硬币一样）
- AUC = 0.8+ → 还不错

**AUC 的好处：不受阈值影响**，不管阈值设0.3还是0.7，AUC都一样。它衡量的是模型本身的排序能力。

## 进阶④：类别不平衡（2026.7.30 攻克）

### 什么是类别不平衡？

> 数据里各类别数量相差巨大。比如医学筛查：健康人 9900 : 癌症 100
> 模型全判健康就 99% 准确率，但一个癌症都没查出来。

### 三种解法

| 方法 | 怎么做 | 适合 |
|:----|:------|:----|
| **① 过采样** | 把少的类别复制多份 | 数据总量不够大时 |
| **② 欠采样** | 把多的类别丢掉一些 | 数据量够大时 |
| **③ 加权 Loss** | 让少数类的错判代价更高 | 不想动数据 |

### 方法③ 加权 Loss（最推荐）

在手写代码的 Loss 里改一处：

```python
# 原版：两类权重一样
loss = -1/m * Σ [y·log(p) + (1-y)·log(1-p)]

# 加权版：少数类的错判代价更高
# 健康:癌症 = 99:1 → 癌症的权重 = 99
weights = np.where(y == 1, class_1_weight, class_0_weight)
loss = -1/m * Σ weights * [y·log(p) + (1-y)·log(1-p)]
```

**直观理解：** 少数类样本少，但每一个都狠狠扣分 → 模型不敢忽视它们。

### sklearn 里一句话

```python
model = LogisticRegression(class_weight='balanced')
```

自动根据各类样本数量反比算权重。

## 进阶⑤：特征缩放（Feature Scaling）（2026.7.30 攻克）

### 什么问题？

多个特征数值不在一个量级：

```
身高：170 cm     ← 数值大
体重：65 kg
年龄：25 岁      ← 数值小
```

年龄的系数 w₃ 要变得很大才能产生影响，身高的 w₁ 一点点就很大。
→ **梯度下降震荡、收敛慢**

### 解法：归一化

| 方法 | 公式 | 映射到 | 适合 |
|:----|:----|:------|:----|
| **Min-Max归一化** | (x - min) / (max - min) | [0, 1] | 数据有明确边界 |
| **Z-score标准化** | (x - μ) / σ | 均值0, 方差1 | 数据有离群点 |

### 代码就一行

```python
# Z-score 标准化（最常用）
from sklearn.preprocessing import StandardScaler
X_norm = StandardScaler().fit_transform(X)
```

### ⚠️ 注意

> **只用训练集的 min/max/μ/σ 去缩放测试集**
> 不能用测试集的统计量，否则相当于偷看答案。

### 直观理解

> 把厘米、公斤、岁统一变成 0~1 之间的数，让模型公平对待每个特征。

## 阈值与代价（2026.7.30 深化讨论）

### 默认阈值为什么是0.5？

> 因为0~1正中间，两种错误代价一样时各占一半。适用于猫狗识别、及格/不及格（代价相当）的场景。

### 代价不对称时怎么调阈值？

**场景：癌症筛查**
| 真实 | 预测健康 | 预测癌症 |
|:----|:--------|:--------|
| 健康 ✅ | TN（没事） | FP（虚惊一场） |
| 癌症 ❌ | ‍ **FN（漏诊！）** | TP（救了命） |

漏掉一个癌症 = 人命关天。所以：
- 阈值**调低**（如0.3）→ 宁可误判健康人为癌症，也不漏真癌症

**场景：垃圾邮件过滤**
误删一封重要邮件代价更大 → 阈值**调高**（如0.8）

### 与假设检验的关联

用户自述联想到假设检验，方向完全正确：

| 假设检验 | 逻辑回归对应 |
|:--------|:-----------|
| 第一类错误 α（弃真） | 把健康人判为癌症 → FP |
| 第二类错误 β（取假） | 把癌症判为健康 → FN |
| 调α↓则β↑ | 调阈值 → 两种错误率此消彼长 |

> 工程上通过 **ROC 曲线 + Youden Index** 找阈值平衡点，让总代价最小。

### 测试集100%≠完美

> 只能说明在这个数据里正确率100%，换数据未必。关键看泛化能力。
> 可能的原因：①数据太简单（如鸢尾花数据集）②模型过拟合了此数据
