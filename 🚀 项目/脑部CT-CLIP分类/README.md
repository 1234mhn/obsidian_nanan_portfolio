## 📌 项目简介

| 项目 | 内容 |
|:----|:-----|
| 任务 | 脑部CT影像中风/正常二分类 |

## 🎯 核心思路

CLIP将图片和文字映射到同一向量空间，通过计算**图片特征**与**类别文字特征**的相似度完成分类：

```
CT图片 ──→ CLIP编码 ──→ 图片特征
                             ↓ 相似度匹配
"急性中风CT片" ──→ 文字编码 ──→ 文字特征
"正常脑部CT片" ──→ 文字编码 ──→ 文字特征
```

## 📊 方法亮点

- **零样本学习**：不用训练，直接拿预训练CLIP分类
- **中文医学提示词**：每个类别10条医学描述（高密度病灶/低密度梗死灶等）
- **类别级特征**：多提示词特征平均，增强鲁棒性
